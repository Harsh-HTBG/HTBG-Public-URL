How to add new client presentations
Step 01 Create or use a project folder in your local git repository (e.g. HTBG-Presentations).
Step 02 Drop your HTML presentation file into that project folder.
Step 03 Commit and push to GitHub (git push origin main).
Step 04 Your presentation will automatically populate here! Share the unique client link directly with your client.
